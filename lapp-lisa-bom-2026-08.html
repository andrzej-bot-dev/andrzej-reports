🏁 Werdykt — co kupować gdzie

  • raspberrypi.dk — boardy i kamery (Zero 2 W 159 DKK, Pi 5 2GB 549 DKK, kamery 249–349 DKK). Dostawa DK→SE zwykle 2–4 dni. ⚠️ API nie zawsze pokazuje stock — potwierdź w koszyku.
  • amazon.se — kabel 22-pin, microSD, powerbank, serwo, PIR, MPU6050, Mini560, AS5600, LoRa. Prime/fast shipping.
  • AliExpress — jak nie spieszy się: serwo (~60 zamiast 280 kr), PIR, MPU6050, AS5600, DS18B20, fisheye USB, LiFePO4. Łącznie można zbić ~800–1 000 kr z rachunku za cenę 2–3 tygodni czekania.
  • Kolejność zakupów pod start MVP (żeby test ruszył najszybciej): raspeberrypi.dk (Zero + kamera Wide) + amazon.se (kabel + SD + powerbank + serwo) — reszta to nice-to-have.
💡 Rachunek ekonomiczny: parking ≈ 80 kr/dzień ≈ 1 680 kr/mies. MVP (~1 500 kr) zwraca się w <1 miesiąca, a V2 z auto-biletem eliminuje stres całkowicie.
Metodologia: raspberrypi.dk — oficjalne WooCommerce Store API (wp-json/wc/store/v1/products, ceny i permalinki z JSON; stock częściowo niewidoczny). amazon.se — parsowanie HTML wyników wyszukiwania (bloki data-asin, ceny z a-offscreen); po ~25 zapytaniach Amazon zaczął zwracać captcha → DS18B20 i 2 zapytania oznaczone jako niesprawdzone.
