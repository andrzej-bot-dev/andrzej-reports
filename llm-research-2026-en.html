🖥️ Hardware Analysis — What to Buy and What You Can Run

🔌 Tier 1 — Microcomputer (Edge)

~500 SEK

Hardware: Raspberry Pi 5 (8GB RAM)

⚡ Speed: 1–5 tok/s

Tragically slow. The machine thinks slower than you type. A simple answer takes 30-60s. Longer prompt — several minutes of silence.

📊 Top models' benchmarks on this hardware

  • Qwen3-0.6B: SWE-bench ~3%, MMLU ~35%
  • Qwen3-1.7B: SWE-bench ~8%, MMLU ~48%
  • Phi-3.5 Tiny: SWE-bench ~5%, Agentic ~10%

🤖 OpenClaw & Daily Use

OpenClaw: Not practical. Even simple tool-calling commands will take minutes. Heartbeat polls would choke. Only use-case: "always-on" IoT assistant for light bulbs, where it barely interprets "turn on the light."

Chat: Frustrating. You'll forget the question by the time you get the answer.

Research: Impossible. This kind of research would take days — each web search + analysis means minutes of waiting.

63 SEK / % SWE-bench
500 SEK ÷ 8% (Qwen3-1.7B) = 63 SEK per point
Cheapest entry point, but minimal results. Like buying a 20 SEK beer — cheap, but won't sustain you.
Verdict: Educational curiosity. Teaches you how LLMs work, but not for productive use. OK as an intelligent thermostat.

💻 Tier 2 — Budget Office Laptop

~2 500 SEK

Hardware: Refurbished ThinkPad T480 / Dell Latitude, 32GB RAM, CPU only

⚡ Speed: 5–10 tok/s

Slower than you read. Text flows word-by-word like an old modem. Simple question: 10-20s. Longer analysis: 1min+. Usable, but requires patience.

📊 Top Models' Benchmarks

  • Gemma 3 4B: SWE-bench 25%, Agentic 35%, MMLU 70%
  • Phi-4 Mini 3.8B: SWE-bench 20%, Agentic 30%, MMLU 68%
  • Qwen3-4B: SWE-bench ~22%, Agentic ~32%, MMLU ~65%

🤖 OpenClaw & Daily Use

OpenClaw: Doable! But with limits. Simple commands (reminders, weather) are OK. Tool calling works, but each call adds several seconds. Heartbeats every 30min will strain the machine. Not recommended for complex multi-agent workflows.

Chat: Useful for simple questions, learning, or writing emails. 4B models handle basic logic but get lost in complex tasks.

Research: Very slow. Research like this would take an hour+. The model struggles with multi-step analysis — not enough parameters for complex reasoning.

100 SEK / % SWE-bench
2 500 SEK ÷ 25% (Gemma 3 4B) = 100 SEK per point
Still the cheapest option with a useful model. 100 SEK per SWE-bench point is like a bus ticket — cheap and gets you there.
Verdict: Great for starting out. For 2500 SEK, you get a model that understands instructions and responds sensibly. Ideal for learning, home automation, simple chat. Not GPT-4 level, but like a fixed GPT-3.5.
